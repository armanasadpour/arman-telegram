# Media Optimizer — افزونه وردپرس (نسخه ۲)

بهینه‌سازی **مرحله‌ای و قابل بازگشت** رسانه‌های وردپرس. مسیر: «رسانه ← بهینه‌ساز رسانه».

## مراحل

### ۱. بررسی (فایل‌های بدون استفاده)
همه تصاویر و ویدیوها بررسی می‌شوند که آیا جایی استفاده شده‌اند:
محتوای نوشته/برگه/محصول، گالری (شورت‌کد و بلوک)، تصویر شاخص، گالری محصول ووکامرس،
فیلدهای سفارشی (ACF، المنتور، صفحه‌سازها)، لوگو و آیکن سایت، تنظیمات قالب، ابزارک‌ها، فهرست‌ها، تصویر دسته‌ها و دیدگاه‌ها.
فایل‌های بدون استفاده را می‌توانید به **قرنطینه** بفرستید: از سایت و کتابخانه رسانه برداشته می‌شوند ولی پاک نمی‌شوند.

### ۲. تبدیل
تصاویر به WebP و ویدیوها به MP4 فشرده (H.264) تبدیل می‌شوند و آدرس‌ها در کل سایت به‌روز می‌شوند.
**فایل‌های اصلی پاک نمی‌شوند** و در پوشه پشتیبان (`uploads/wpmo-backup`) نگه داشته می‌شوند.

### ۳. تایید مدیر
- **تایید** ← فایل اصلی برای همیشه حذف می‌شود و فضا آزاد می‌شود.
- **بازگردانی** ← فایل اصلی، همه سایزها، نوع فایل و همه لینک‌های سایت دقیقاً به حالت قبل برمی‌گردند.
- برای قرنطینه: **حذف دائمی** یا **بازگردانی**.

امکان مقایسه فایل جدید با فایل اصلی قبل از تایید وجود دارد.

## آپلودهای جدید
تصاویر بلافاصله به WebP تبدیل و ویدیوها در پس‌زمینه فشرده می‌شوند. اصل فایل‌ها تا تایید مدیر نگه داشته می‌شوند
(اگر «نیاز به تایید مدیر» در تنظیمات خاموش باشد، اصلی‌ها بلافاصله حذف می‌شوند).

## WP-CLI
```bash
wp media-optimizer status
wp media-optimizer scan                 # ۱) بررسی
wp media-optimizer quarantine           # ۱) انتقال بدون‌استفاده‌ها به قرنطینه
wp media-optimizer convert              # ۲) تبدیل (--type=image|video)
wp media-optimizer approve --all        # ۳) تایید و حذف اصلی‌ها
wp media-optimizer revert --all         # ۳) بازگردانی
wp media-optimizer restore --all        # بازگردانی از قرنطینه
wp media-optimizer purge --all          # حذف دائمی قرنطینه
```

## پیش‌نیازها
- وردپرس 5.8+ و PHP 7.4+
- Imagick یا GD با پشتیبانی WebP
- برای ویدیو: FFmpeg روی سرور و فعال بودن `exec` (روی VPS: `apt install ffmpeg`)

## نکات
- قبل از شروع از سایت بکاپ بگیرید.
- تصاویری که فقط در فایل‌های قالب یا CSS استفاده شده‌اند قابل تشخیص نیستند؛ قبل از حذف دائمی قرنطینه، سایت را بررسی کنید.
- پوشه پشتیبان با `.htaccess` محافظت می‌شود (روی Nginx دسترسی مستقیم به `wp-content/uploads/wpmo-backup` را ببندید).
- پس از بهینه‌سازی، کش سایت/CDN را پاک کنید.
