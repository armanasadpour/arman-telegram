# Media Optimizer — افزونه وردپرس (WebP + فشرده‌سازی ویدیو)

## امکانات
- **تبدیل خودکار تصاویر به WebP** بلافاصله پس از آپلود (JPG، PNG، GIF، BMP، TIFF). فایل اصلی حذف می‌شود و همه سایزهای وردپرس از روی WebP ساخته می‌شوند.
- **فشرده‌سازی ویدیو** با FFmpeg (H.264 + AAC، MP4، faststart برای پخش سریع). پس از آپلود و در پس‌زمینه (WP-Cron) انجام می‌شود تا آپلود کند نشود. فرمت‌های MOV، AVI، WMV، MKV، 3GP، FLV به MP4 تبدیل می‌شوند.
- **بهینه‌سازی همه رسانه‌های موجود سایت** از مسیر «رسانه ← بهینه‌ساز رسانه» یا با WP-CLI:
  - تبدیل تصویر به WebP و ساخت دوباره همه سایزها
  - فشرده‌سازی ویدیو (اگر نتیجه کوچک‌تر نباشد، فایل اصلی دست‌نخورده می‌ماند)
  - **جایگزینی خودکار آدرس‌ها** در نوشته‌ها، برگه‌ها، متاها (Elementor و…)، تنظیمات و ابزارک‌ها (داده‌های serialize شده هم سالم می‌مانند)
  - **حذف فایل اصلی** و سایزهای قدیمی
- تنظیمات: کیفیت WebP، حداکثر عرض تصویر/ویدیو، CRF، preset، بیت‌ریت صدا، رد کردن GIF متحرک، روشن/خاموش کردن حذف فایل اصلی.

## نصب
1. فایل `wp-media-optimizer.zip` را از «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب و فعال کنید.
2. به «رسانه ← بهینه‌ساز رسانه» بروید و وضعیت WebP و FFmpeg را بررسی کنید.
3. **از فایل‌ها و دیتابیس بکاپ بگیرید**، بعد روی «شروع بهینه‌سازی» بزنید.

## پیش‌نیازها
- وردپرس 5.8+ و PHP 7.4+
- Imagick یا GD با پشتیبانی WebP (در اغلب هاست‌ها هست)
- برای ویدیو: **FFmpeg** روی سرور و فعال بودن تابع `exec` در PHP. در بسیاری از هاست‌های اشتراکی این امکان نیست؛ در آن صورت تصاویر تبدیل می‌شوند ولی ویدیوها نه. (روی VPS: `apt install ffmpeg`)

## WP-CLI (برای سایت‌های بزرگ، بدون محدودیت زمان)
```bash
wp media-optimizer status
wp media-optimizer run                 # همه
wp media-optimizer run --type=image    # فقط تصاویر
wp media-optimizer run --type=video    # فقط ویدیوها
wp media-optimizer run --retry-errors  # تلاش دوباره برای موارد خطادار
```

## نکات
- تنظیمات پیش‌فرض (WebP کیفیت ۸۲، ویدیو CRF ۲۶ با preset slow) افت کیفیت قابل مشاهده ندارند و حجم را به‌طور قابل توجهی کم می‌کنند.
- اگر از CDN یا افزونه کش استفاده می‌کنید، بعد از بهینه‌سازی کش را پاک کنید.
- هر فایل فقط یک بار بهینه می‌شود (برای جلوگیری از افت کیفیت در فشرده‌سازی‌های پشت سر هم).
