# راهنمای نصب پنل روی cPanel (بدون SSH)

فایل لازم: `vpn-panel-0.2.1.zip` (حدود ۱۷ مگابایت؛ همه وابستگی‌ها داخل آن است).

## ۰. پیش از نصب
1. **نسخه PHP:** cPanel ← **MultiPHP Manager** (یا **Select PHP Version**) ← برای دامنه/ساب‌دامین، **PHP 8.3** را انتخاب کنید. (هاست شما الان روی 8.2 است؛ این مرحله الزامی است.)
2. **SSL:** cPanel ← **SSL/TLS Status** ← برای دامنه AutoSSL را فعال کنید تا پنل روی `https` باز شود.

## ۱. ساخت دیتابیس
cPanel ← **MySQL Databases**:
1. یک دیتابیس جدید بسازید (مثلاً `monino_panel`).
2. یک کاربر جدید با رمز قوی بسازید.
3. در بخش **Add User To Database** کاربر را به دیتابیس اضافه کنید و **ALL PRIVILEGES** را بزنید.

> نام کامل دیتابیس و کاربر معمولاً با پیشوند حساب cPanel است (مثلاً `monino_monino_panel`). همان نام کامل را در نصب‌کننده وارد کنید.

## ۲. آپلود فایل‌ها — یکی از دو روش

### روش الف (پیشنهادی): ساب‌دامین مستقل
1. cPanel ← **Domains** ← یک ساب‌دامین بسازید، مثلاً `panel.monino.ir`، و در **Document Root** بنویسید: `vpn-panel/public`
2. File Manager ← پوشه `vpn-panel` (که cPanel ساخت) را باز کنید، ZIP را آپلود و **Extract** کنید.
3. آدرس نصب: `https://panel.monino.ir/install.php`

در این روش کد برنامه و فایل `.env` کاملاً بیرون از مسیر وب هستند.

### روش ب: داخل public_html (یا یک زیرپوشه آن)
1. File Manager ← `public_html` (یا مثلاً `public_html/panel`) ← ZIP را آپلود و **Extract** کنید.
2. فایل `.htaccess` همراه بسته، همه درخواست‌ها را به پوشه `public` می‌برد و دسترسی به `.env`، `vendor`، `storage` و کد را مسدود می‌کند.
3. آدرس نصب: `https://monino.ir/install.php` (یا `https://monino.ir/panel/install.php`)

> اگر فایل‌های ابزار تست فاز ۱ هنوز در `public_html` هستند، ابتدا پاکشان کنید (به‌جز `php.ini`).

## ۳. اجرای نصب‌کننده
صفحه `install.php` به ترتیب:
1. **پیش‌نیازها** را بررسی می‌کند (نسخه PHP، افزونه‌ها، دسترسی پوشه‌ها). موارد قرمز را برطرف و صفحه را تازه کنید.
2. اطلاعات **سامانه** (آدرس، نام، منطقه زمانی)، **دیتابیس** و **مدیرکل** را می‌گیرد.
3. اتصال دیتابیس را تست می‌کند. اگر دیتابیس خالی نباشد، **نصب نمی‌کند** (تا داده‌ای پاک نشود).
4. فایل `.env` را با کلیدهای تصادفی، حالت عملیاتی (Debug خاموش) می‌سازد، جداول را ایجاد می‌کند، مدیرکل را می‌سازد و نصب را **قفل** می‌کند.
5. در پایان `install.php` خودش را حذف می‌کند؛ اگر نتوانست، از File Manager حذفش کنید.

## ۴. Cron Job
cPanel ← **Cron Jobs** ← **Common Settings: Once Per Minute** و در Command دقیقاً همان دستوری را بگذارید که صفحه پایان نصب (و صفحه «وضعیت سرویس‌ها» در پنل) نشان می‌دهد؛ شکل کلی:
```
/usr/local/bin/php /home/USERNAME/vpn-panel/artisan schedule:run >/dev/null 2>&1
```
چند دقیقه بعد، در پنل ← **وضعیت سرویس‌ها**، ردیف «Cron» باید «سالم» شود.

اگر هاست اجازه اجرای PHP از Cron را نمی‌دهد، آدرس **Web-Cron** که در همان صفحه نمایش داده می‌شود را با `wget` هر دقیقه فراخوانی کنید. این آدرس یک کلید محرمانه دارد؛ آن را جایی منتشر نکنید.

## ۵. فونت IRANSans
فونت در همه وزن‌ها داخل بسته است و کاری لازم نیست.

## ۶. پشتیبان‌گیری (حداقل)
- **دیتابیس:** cPanel ← Backup ← Download a MySQL Database Backup.
- **فایل `.env`:** حاوی `APP_KEY` است؛ بدون آن تنظیمات رمزنگاری‌شده (مثل توکن‌ها در فازهای بعد) قابل بازیابی نیستند. یک نسخه از آن را جای امن نگه دارید.
(راهنمای کامل پشتیبان‌گیری و بازیابی در فاز ۱۰ تحویل می‌شود.)

| مشکل | راه‌حل |
|---|---|
| صفحه سفید یا خطای ۵۰۰ | نسخه PHP را روی 8.3 بگذارید؛ لاگ: `storage/logs/` |
| ۴۰۳ روی همه صفحات | دسترسی پوشه‌ها 755 و فایل‌ها 644 باشد؛ ModSecurity را بررسی کنید |
