# توسعه میکروتیک (L2TP و WireGuard)

## مرحله ۱ — اتصال به روتر (نسخه 1.1.0) ✅
- **چند روتری:** جدول `routers`؛ رمز رمزنگاری‌شده؛ هر روتر L2TP و/یا WireGuard را جدا فعال می‌کند.
- **سه روش اتصال:**
  - REST API روی HTTPS (پیشنهادی؛ RouterOS 7.1+، سرویس www-ssl).
  - API-SSL (پورت 8729).
  - API ساده (پورت 8728؛ رمز رمزنگاری نمی‌شود — فقط شبکه خصوصی).
- **اعتماد به گواهی (Pinning):** گواهی خودامضای روتر بدون ارسال رمز دریافت و SHA-256 آن نمایش داده می‌شود تا با `/certificate print detail` مقایسه و تأیید شود. پس از آن پنل فقط به همان کلید رمز می‌فرستد؛ تغییر آدرس/روش اتصال اعتماد را باطل می‌کند.
- **تست اتصال:** نام، نسخه، برد، لایسنس، CPU، حافظه، uptime.
- **بررسی آمادگی (فقط خواندنی):** محدودیت IP سرویس مدیریتی، سرویس‌های ناامن، سرور L2TP، IPsec، پروفایل PPP با Pool، کاربران PPP موجود، اینترفیس WireGuard و آدرس آن، Peerهای موجود. کلیدهای خصوصی و PSK هرگز ذخیره یا نمایش داده نمی‌شوند.
- **اسکریپت راه‌اندازی:** گروه و کاربر مخصوص پنل محدود به IP هاست، گواهی خودامضا، فعال‌سازی سرویس فقط برای IP هاست.
- **پایش:** `routers:health` هر ۵ دقیقه؛ هشدار قطع/وصل در ربات.
- **تست‌ها:** ۱۰ تست (شبیه‌ساز واقعی RouterOS API و HTTPS با گواهی: ورود، رمز اشتباه، عدم تطابق گواهی، بررسی آمادگی، پایش)؛ کل ۲۱۳ تست روی SQLite و MariaDB سبز. تست مرورگری روی Apache: افزودن روتر ← دریافت و تأیید گواهی ← تست ← فعال‌سازی پروتکل‌ها.

## مراحل بعد (پیشنهادی)
2. **مدل اکانت چندپروتکلی و بسته‌ها:** نوع سرویس هر بسته/گروه (OpenVPN-IBSng / L2TP / WireGuard)، حجم و روز دلخواه، دسته‌بندی و قیمت‌گذاری مشترک با موتور فعلی.

## نسخه ۱.۲ — اکانت‌های L2TP و WireGuard

### آماده‌سازی روتر (یک بار)
- **L2TP:** در Winbox → PPP → Interface → L2TP Server: گزینه Enabled، Use IPsec = required و یک IPsec Secret. یک پروفایل PPP با Local Address و Remote Address (یک IP Pool) داشته باشید.
- **WireGuard:** در Winbox → WireGuard یک اینترفیس (مثلاً `wg1`، پورت 13231) بسازید. در IP → Addresses یک آدرس مثل `10.66.0.1/24` روی آن بگذارید. یک NAT masquerade برای این شبکه بسازید و پورت UDP را در فایروال باز کنید.
- **کاربر `panel`** باید دسترسی `write` داشته باشد (در اسکریپت راه‌اندازی هست).

### در پنل
1. **روترها:** «تست اتصال» را بزنید، بعد L2TP یا WireGuard را روشن کنید.
2. **گروه‌های L2TP / WireGuard:** برای هر روتر گروه بسازید.
   - **L2TP:** پروفایل PPP را انتخاب کنید. می‌توانید یک پروفایل جدید با محدودیت سرعت بسازید. حداکثر اتصال همزمان را هم تعیین کنید. کلید IPsec از روتر خوانده می‌شود.
   - **WireGuard:** اینترفیس را انتخاب کنید. کلید عمومی، پورت و شبکه خودکار خوانده می‌شود. محدودیت سرعت اختیاری است و با Simple Queue اعمال می‌شود.
3. **بسته‌ها:** پروتکل «میکروتیک» را بزنید و گروه را انتخاب کنید (اکانت جدید)، یا بسته تمدید و افزایش حجم بسازید. قیمت‌گذاری، تخفیف‌ها، قیمت ویژه همکاران و دسته‌ها مثل OpenVPN کار می‌کنند.
4. **اکانت‌های L2TP / WireGuard → ساخت اکانت:** یا از روی بسته، یا با حجم و روز دلخواه.
   - برای **L2TP:** نام کاربری، رمز، آدرس سرور و کلید IPsec نمایش داده می‌شود.
   - برای **WireGuard:** فایل `.conf` و QR code نمایش داده می‌شود (QR داخل خود پنل ساخته می‌شود).

### حسابداری مصرف
- کرون `mt:accounting` هر دقیقه اجرا می‌شود و مصرف هر نشست L2TP و هر Peer وایرگارد را از روتر می‌خواند.
- ریبوت روتر یا صفر شدن شمارنده‌ها تشخیص داده می‌شود و مصرفی دوبار شمرده نمی‌شود.
- مدت اعتبار از اولین اتصال شروع می‌شود؛ این را در تنظیمات گروه می‌توانید عوض کنید.
- **اعمال محدودیت‌ها:**
  - اکانت منقضی یا حجم‌تمام روی روتر غیرفعال و اتصالش قطع می‌شود.
  - با تمدید یا افزایش حجم دوباره فعال می‌شود.
  - نشست‌های L2TP بیش از حد مجاز قطع می‌شوند.
- **منبع حقیقت پنل است:**
  - اگر کسی روی روتر اکانت را دستی فعال کند، پنل دوباره غیرفعالش می‌کند.
  - اگر Secret یا Peer از روتر پاک شود، با همان اطلاعات دوباره ساخته می‌شود.
- **محدودیت این روش:** چند مگابایتی که یک نشست بین آخرین خواندن و قطع شدنش مصرف می‌کند دیده نمی‌شود (حداکثر یک دقیقه). اگر کرون متوقف شود، قطع خودکار هم انجام نمی‌شود.
- **روتر در دسترس نیست:** اکانت در حالت «در حال ساخت» می‌ماند و هر دقیقه دوباره تلاش می‌شود. مبلغ فروش نگه داشته می‌شود و پس از ساخت تکمیل می‌شود. اگر روتر ساخت را رد کند، مبلغ خودکار برمی‌گردد.

### فروش و ربات
- همکاران در پورتال همکاری اکانت L2TP و WireGuard می‌فروشند و تمدید می‌کنند. اطلاعات اتصال و QR را در صفحه اکانت می‌بینند.
- مشتری در ربات بسته را می‌خرد و اطلاعات اتصال (برای WireGuard متن فایل) را به‌صورت پیام محرمانه می‌گیرد.
- مشتری می‌تواند اکانت L2TP خود را با نام کاربری و رمز به ربات اضافه کند.
- «اکانت‌های من» و «تمدید اکانت من» در ربات شامل این اکانت‌ها هم هست.
- هشدار نزدیک شدن انقضا و تمام شدن حجم برای این اکانت‌ها هم ارسال می‌شود، و گزارش روزانه مدیر بخش L2TP/WireGuard دارد.

### دسترسی‌ها
نقش‌ها یک بخش جدید دارند: «اکانت‌های میکروتیک».
- دیدن رمز، فایل و QR، تغییر رمز و ساخت کلید جدید «عملیات حساس» است و تأیید دوباره رمز ورود پنل را لازم دارد.
- ساخت و ویرایش گروه‌ها با دسترسی ویرایش روترهاست.
