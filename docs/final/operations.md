# عملیات و نگهداری

## کارهای زمان‌بندی‌شده (همه با یک Cron هر دقیقه)
| فرمان | تناوب | کار |
|---|---|---|
| `ibs:sync-onlines` | ۱ دقیقه | کاربران آنلاین |
| `ibs:retry-jobs` | ۱ دقیقه | ادامه ساخت‌های نیمه‌کاره |
| `ibs:import-step` | ۱ دقیقه | وارد کردن اکانت‌ها (در صورت فعال بودن) |
| `accounts:cleanup-step` | ۱ دقیقه | حذف گروهی (در صورت فعال بودن) |
| `resellers:sync-sales` | ۱ دقیقه | تکمیل فروش‌های در انتظار |
| `payments:reverify` | ۱ دقیقه | تأیید دوباره پرداخت‌های نامشخص، بررسی تتر، تکمیل سفارش‌ها |
| `bots:send` | ۱ دقیقه | ارسال صف پیام‌های ربات |
| `ibs:sync-accounts` | ۵ دقیقه | به‌روزرسانی اکانت‌های قدیمی‌تر |
| `alerts:run` | ۱۰ دقیقه | اعلان‌ها و گزارش‌های روزانه + پاک‌سازی |
| `ibs:sync-catalog` | ساعتی | گروه‌ها و تعرفه‌ها |
| `wallets:reconcile` | روزانه | تطبیق همه کیف پول‌ها با دفتر کل؛ مغایرت ← هشدار به مدیر در ربات |

## پایش روزانه
1. داشبورد: کادر «نیازمند رسیدگی» خالی باشد.
2. وضعیت سرویس‌ها: Cron، دیتابیس و سرور سبز.
3. ربات‌ها ← صف پیام‌ها: پیام ناموفق نباشد.
4. گزارش روزانه مدیر در ربات.

## رسیدگی به موارد
| مورد | چه کنیم |
|---|---|
| فروش/سفارش «نیازمند رسیدگی» | در سرور IBSng ببینید اکانت ساخته/تمدید شده یا نه؛ اگر نشده «برگشت به کیف پول»؛ اگر شده، Cron خودش تکمیل می‌کند (ساخت‌های نیمه‌کاره) |
| ساخت نیمه‌کاره | اکانت‌ها ← ساخت‌های نیمه‌کاره ← «تلاش مجدد» یا «رسیدگی شد» با توضیح |
| پرداخت آنلاین «در درگاه» مانده | خودکار تا ۲ ساعت دوباره بررسی و سپس منقضی می‌شود؛ «بررسی دوباره» در صفحه پرداخت |
| تتر در انتظار بررسی | پیام خطا را بخوانید؛ در اکسپلورر چک کنید؛ «تأیید و شارژ» یا «رد» |
| قطع سرور IBSng | هشدار در ربات؛ ساخت/تمدید متوقف و پس از وصل شدن ادامه می‌یابد |

## امنیت
- رمزها و کلیدها (IBSng، توکن ربات‌ها، کلید درگاه‌ها، API اکسپلورر) با APP_KEY رمزنگاری می‌شوند و هرگز در صفحه یا لاگ نمایش داده نمی‌شوند.
- عملیات حساس (شارژ/کسر کیف پول، تأیید پرداخت، تنظیم درگاه و توکن، حذف اکانت/گروهی، مشاهده رمز) تأیید مجدد رمز می‌خواهد و با دلیل ثبت می‌شود.
- برای هر کاربر فقط دسترسی لازم را بدهید؛ نقش «مدیرکل» را محدود نگه دارید.
- اگر کد واسط تلگرام یا آدرس وبهوک لو رفت: ربات‌ها ← «تعویض آدرس مخفی» ← «اتصال».
- رمز مدیر IBSng پنل را مختص پنل و محدود به IP هاست تعریف کنید.
- لاگ‌ها: `storage/logs/` (۱۴ روز).
