## کیفیت
- **۲۰۳ تست خودکار** (۲۳٬۰۰۰+ assertion) روی SQLite و MariaDB 10.11 (با ساعت تهران) — همه سبز.
- تست پیمایش: هر ۳۸ صفحه برای مهمان ← ورود، کاربر بدون دسترسی ← ۴۰۳، همکار ← فقط پنل خودش، مدیرکل ← بدون خطا.
- هر نسخه روی Apache واقعی با ارتقای مرحله‌به‌مرحله (0.2 → 1.0) و شبیه‌سازهای IBSng، پیام‌رسان و زرین‌پال آزمایش شده است.
- `composer audit`: آسیب‌پذیری شناخته‌شده‌ای نیست.

### بازبینی امنیت (فاز ۱۰)
CSRF روی همه فرم‌ها (به‌جز وبهوک‌ها و بازگشت بانک که با امضا/آدرس مخفی و تأیید سرور‌به‌سرور محافظت می‌شوند)؛ CSP سخت‌گیرانه (فقط مبدأ همان درگاه در صفحه پرداخت)؛ هدرهای امنیتی؛ محدودیت درخواست برای هر مسیر؛ همه SQLهای خام ثابت یا پارامتری؛ خروجی Blade escaped (به‌جز آیکون‌های داخلی)؛ جلوگیری از تزریق فرمول در CSV؛ رسیدها خارج از مسیر وب و فقط با دسترسی؛ رمزها و توکن‌ها رمزنگاری‌شده و حذف از لاگ؛ دیباگ خاموش در نصب؛ `.env` و پوشه‌های برنامه از وب مسدود.

## ⚠️ چک‌لیست آزمایش روی محیط واقعی (قبل از استفاده تجاری)
این موارد فقط با سرور/حساب واقعی شما قابل تأیید است و در محیط توسعه با شبیه‌ساز آزموده شده‌اند:
1. **IBSng:** چک‌لیست فاز ۳ (searchUser، باز کردن قفل، getUserInfo چندتایی)، ساخت گروه از پنل، ساخت شارژ `Volume-MB` در IBSng برای بسته‌های حجمی.
2. **وارد کردن اکانت‌ها** تا پایان (بعد از رفع اشکال 0.7.1).
3. **ربات‌ها:** «تست دسترسی هاست به پیام‌رسان‌ها»؛ اتصال بله و روبیکا (پاسخ getMe را ببینید)؛ تلگرام از طریق Cloudflare Worker.
4. **درگاه‌ها:** با هر درگاه یک پرداخت کم‌مبلغ واقعی؛ ثبت آدرس بازگشت در پنل پذیرندگی.
5. **تتر:** دسترسی هاست به TronGrid/Etherscan؛ یک انتقال کوچک آزمایشی.
6. **اعلان‌ها:** اتصال حساب مدیر به ربات و دریافت «گزارش آزمایشی».
7. **پشتیبان:** یک بار پشتیبان دیتابیس + `.env` و آزمایش بازیابی روی دیتابیس آزمایشی.

## خارج از دامنه این نسخه (طبق تصمیم شما)
L2TP و WireGuard روی میکروتیک (IBSng فقط OpenVPN را مدیریت می‌کند) — برای توسعه بعدی.
