# نصب، به‌روزرسانی، پشتیبان‌گیری — نسخه 1.0

## نصب تازه (cPanel، بدون SSH)
1. **PHP 8.3** (MultiPHP Manager) و **SSL** (AutoSSL) را برای دامنه فعال کنید.
2. در **MySQL Databases** یک دیتابیس و کاربر با ALL PRIVILEGES بسازید.
3. ZIP را در پوشه مقصد (ترجیحاً ساب‌دامینی که Document Root آن `…/public` است، یا داخل `public_html`) آپلود و Extract کنید.
4. `https://دامنه/install.php` را باز کنید؛ پیش‌نیازها، دیتابیس، مدیرکل را وارد کنید. نصب‌کننده `.env` را می‌سازد، جداول را ایجاد و خودش را قفل/حذف می‌کند.
5. **Cron Job** — Once Per Minute — دستوری که صفحه «وضعیت سرویس‌ها» نشان می‌دهد:
   `/usr/local/bin/php /home/USER/مسیر/artisan schedule:run >/dev/null 2>&1`
   (اگر Cron اجرای PHP را نمی‌دهد: آدرس Web-Cron همان صفحه با wget.)
6. در پنل ← «اتصال به سرور IBSng»: IP، پورت 1235، نام کاربری و رمز مدیر IBSng ← «تست اتصال» ← همگام‌سازی گروه‌ها ← «شروع وارد کردن» اکانت‌ها.

## به‌روزرسانی (هر نسخه جدید)
1. **پشتیبان دیتابیس** بگیرید (پایین را ببینید).
2. ZIP نسخه جدید را در همان پوشه آپلود و Extract کنید و «جایگزینی فایل‌ها» را تأیید کنید. `.env` و `storage` دست نمی‌خورند.
3. وارد پنل شوید؛ پیام «نسخه جدید نصب شده» ← رمز را وارد و «اجرای به‌روزرسانی» را بزنید (یک مرحله). در این فاصله کاربران دیگر صفحه «در حال به‌روزرسانی» می‌بینند.
4. «وضعیت سرویس‌ها» را بررسی کنید (همه سبز).

## پشتیبان‌گیری و بازیابی
| چه | چطور | چند وقت یک بار |
|---|---|---|
| دیتابیس | cPanel ← Backup ← Download a MySQL Database Backup (یا Backup Wizard) | روزانه (یا cPanel Backup خودکار) |
| فایل `.env` | از File Manager دانلود؛ **حاوی APP_KEY** است — بدون آن توکن ربات‌ها، کلیدهای درگاه و رمز IBSng قابل رمزگشایی نیستند | یک بار پس از نصب و پس از هر تغییر |
| `storage/app/private/receipts` | رسیدهای کارت‌به‌کارت | هفتگی |

**بازیابی:** همان نسخه پنل را Extract کنید، `.env` قبلی را برگردانید، دیتابیس را از cPanel ← phpMyAdmin ← Import بازیابی کنید، سپس وارد پنل شوید (اگر نسخه جدیدتر است، «اجرای به‌روزرسانی»).

## انتقال به هاست دیگر
همان مراحل بازیابی؛ در `.env` فقط `APP_URL` و اطلاعات دیتابیس را اصلاح کنید. آدرس بازگشت درگاه‌ها و وبهوک ربات‌ها را دوباره ثبت کنید (دکمه «اتصال» در صفحه ربات‌ها).
