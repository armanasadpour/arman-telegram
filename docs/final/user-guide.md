# راهنمای استفاده

## مدیر
| بخش | کارها |
|---|---|
| **داشبورد** | فروش امروز/۷/۳۰ روز، نمودار ۱۴ روزه، موارد نیازمند رسیدگی، وضعیت اکانت‌ها و سرویس‌ها |
| **گزارش‌ها** | بازه دلخواه با تقویم شمسی؛ درآمد، پرداخت‌ها به تفکیک روش، عملکرد همکاران، اکانت‌ها به تفکیک گروه؛ **خروجی اکسل** (فروش، خرید مستقیم، پرداخت‌ها، دفتر کل، همکاران، اکانت‌ها) |
| **اکانت‌ها** | جستجو و فیلتر؛ ساخت (دستی یا از بسته، رمز دلخواه)؛ تمدید، افزایش حجم، اعمال بسته، قفل، تغییر/مشاهده رمز، حذف؛ نوار باقی‌مانده زمان و حجم؛ وارد کردن همه اکانت‌های سرور؛ **حذف گروهی منقضی‌های قدیمی** |
| **گروه‌ها و تعرفه‌ها** | همگام‌سازی، **ساخت و ویرایش گروه در سرور** |
| **بسته‌ها / تخفیف‌ها** | بسته اکانت جدید، تمدید، افزایش حجم؛ تخفیف درصدی/مبلغی با بازه تاریخ |
| **همکاران فروش** | ساخت همکار، تخفیف سراسری/دسته‌ای/قیمت اختصاصی، شارژ و کسر دستی کیف پول (با دلیل)، دفتر کل، فروش‌ها، رسیدگی به فروش‌های نامشخص |
| **پرداخت‌ها** | همه پرداخت‌ها؛ تأیید/رد کارت‌به‌کارت و تتر (با دیدن رسید)؛ سفارش‌های مشتری نیازمند رسیدگی |
| **درگاه‌های پرداخت** | زرین‌پال، سامان، ملت، سداد، کارت‌به‌کارت (تا ۳ کارت)، تتر (نرخ، آدرس‌ها، کلید اکسپلورر) |
| **ربات‌ها** | توکن تلگرام/بله/روبیکا، مسیر تلگرام (مستقیم / Cloudflare / Apps Script)، اتصال، تست دسترسی، متن خوش‌آمد و پشتیبانی، صف پیام‌ها |
| **اعلان‌ها** | یادآوری انقضا/حجم به مشتری، خلاصه روزانه همکار، گزارش روزانه مدیر، هشدار قطع سرور |
| **کاربران پنل / نقش‌ها** | کاربر و نقش با دسترسی‌های جزئی (مشاهده/ایجاد/ویرایش/حذف/حساس) |
| **گزارش رویدادها** | همه عملیات با کاربر، زمان، قبل/بعد و دلیل؛ زنجیره هش ضد دست‌کاری |
| **وضعیت سرویس‌ها** | Cron، دیتابیس، سرور IBSng، به‌روزرسانی |

## همکار (پنل `/r` و ربات)
پیشخوان با نمودار سود، فروش اکانت جدید (نام کاربری و رمز دلخواه)، تمدید و افزایش حجم اکانت‌های خود، کیف پول و شارژ آن (آنلاین / کارت‌به‌کارت / تتر)، قیمت‌های اختصاصی، خروجی اکسل فروش‌ها، تراکنش‌ها و اکانت‌ها. در ربات: پس از «ورود همکاران» با کد یک‌بارمصرف، همه همین کارها.

## مشتری (ربات)
افزودن اکانت با نام کاربری و رمز، مشاهده باقی‌مانده با نوار، **خرید** و **تمدید** با پرداخت آنلاین/کارت‌به‌کارت/تتر یا موجودی کیف پول، تعرفه‌ها، پشتیبانی؛ دریافت یادآوری انقضا و حجم.

## اصول مالی
- هر پرداخت موفق فقط یک بار کیف پول را شارژ می‌کند؛ خرید از کیف پول کسر می‌شود.
- دفتر کل تغییرناپذیر است؛ اصلاح فقط با ردیف معکوس. موجودی منفی ممکن نیست.
- شکست قطعی ساخت اکانت ← بازگشت خودکار وجه به کیف پول؛ نتیجه نامشخص ← «نیازمند رسیدگی» (پول نگه داشته می‌شود تا روشن شود).
