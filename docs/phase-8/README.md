# فاز ۸ — اعلان‌ها و کارهای زمان‌بندی‌شده

## اعلان‌ها (از طریق ربات‌ها؛ Cron هر ۱۰ دقیقه `alerts:run`)
| گیرنده | اعلان | تکرار |
|---|---|---|
| مشتری (اکانت متصل به ربات) | انقضا نزدیک است (پیش‌فرض ۳ و ۱ روز مانده) | یک بار برای هر آستانه در هر دوره انقضا |
| مشتری | اکانت منقضی شد | یک بار برای هر تاریخ انقضا |
| مشتری | حجم کم است (پیش‌فرض ≤ ۲۰٪ یا ≤ ۱ گیگ) / حجم تمام شد | یک بار تا افزایش حجم بعدی |
| همکار | خلاصه روزانه: اکانت‌های در آستانه انقضا و منقضی‌شده دیروز، موجودی؛ هشدار موجودی کم | روزانه |
| مدیر | گزارش روزانه: فروش همکاران، خرید مشتریان، پرداخت‌ها به تفکیک روش، اکانت‌های جدید، در آستانه انقضا، موارد نیازمند رسیدگی، وضعیت سرور | روزانه در ساعت تعیین‌شده |
| مدیر | قطع و وصل شدن ارتباط با سرور IBSng | هنگام تغییر وضعیت |

- پیش از اعلان به مشتری، اطلاعات اکانت از سرور تازه می‌شود (اگر تمدید شده باشد اعلان نمی‌رود).
- جلوگیری از اعلان تکراری با جدول `alert_log` (کلید یکتا).
- همه آستانه‌ها و فعال/غیرفعال بودن هر اعلان در «تنظیمات اعلان‌ها»؛ دکمه ارسال گزارش آزمایشی.
- «صف پیام‌ها»: فهرست پیام‌های ارسالی/ناموفق ربات‌ها برای مدیر.
- پاک‌سازی دوره‌ای: پیام‌های ارسال‌شده قدیمی (۳۰ روز)، کدهای اتصال منقضی، سابقه اعلان‌ها (۱۲۰ روز).

## نمایش باقی‌مانده
نوار پیشرفت رنگی (سبز ← نارنجی ← قرمز) با درصد و مقدار برای زمان و حجم، در صفحه اکانت مدیر، پنل همکار و کارت اکانت در ربات (▰▰▰▱▱).

## معیارهای پذیرش
- [x] هر اعلان دقیقاً یک بار؛ اکانت تمدیدشده اعلان انقضا نمی‌گیرد.
- [x] گزارش روزانه فقط یک بار در روز و پس از ساعت تعیین‌شده.
- [x] قطع/وصل سرور فقط هنگام تغییر وضعیت اعلام می‌شود.
- [x] تنظیمات فقط با دسترسی؛ تست‌های قبلی سبز.

## نتیجه (نسخه 0.8.0)
- **تست‌ها:** ۱۹۵ تست روی SQLite و MariaDB سبز (۸ تست اعلان‌ها + ۲ تست نوارها).
  - یادآوری ۳ روز و ۱ روز هر کدام یک بار، سپس اعلام انقضا یک بار؛ اکانتی که در سرور تمدید شده اعلان نمی‌گیرد؛ حجم کم و اتمام حجم یک بار؛ خاموش کردن هر اعلان.
  - گزارش روزانه مدیر فقط بعد از ساعت تعیین‌شده و فقط یک بار در روز؛ خلاصه همکار با اکانت‌های در آستانه انقضا و هشدار موجودی؛ قطع/وصل سرور فقط هنگام تغییر.
- **تست واقعی روی Apache:** ارتقا 0.7.1 → 0.8.0؛ نوارهای زمان (۲۷٪ نارنجی) و حجم (۱۲٪ قرمز) در صفحه اکانت و کارت ربات؛ `alerts:run` هشدار حجم کم را یک بار برای مشتری ربات فرستاد، اجرای دوم چیزی نفرستاد.
- **حجم کل اکانت‌های واردشده:** برای اکانت‌هایی که پنل نساخته، «حجم کل» = بیشترین حجم باقی‌مانده‌ای که پنل دیده (با هر افزایش حجم به‌روز می‌شود)؛ درصد از همان زمان محاسبه می‌شود.
