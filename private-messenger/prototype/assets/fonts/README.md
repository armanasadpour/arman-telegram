# فونت‌ها

فایل‌های IRANSans (تجاری) به دلیل مجوز در مخزن قرار نگرفته‌اند. پس از تهیه مجوز وب/اپلیکیشن، این فایل‌ها را اینجا قرار دهید:

- `IRANSans-Light.woff2` (300)
- `IRANSans-Regular.woff2` (400)
- `IRANSans-Medium.woff2` (500)
- `IRANSans-Bold.woff2` (700)

در نبود آن‌ها، صفحه از Vazirmatn (در صورت نصب روی سیستم) و سپس Tahoma/فونت سیستم استفاده می‌کند. هیچ فونتی از CDN بارگذاری نمی‌شود.
