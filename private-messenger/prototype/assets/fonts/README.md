# فونت‌ها

فونت اصلی IRANSans است (مجوز تجاری توسط کارفرما تهیه شده). برای دیدن نمونه اولیه با فونت اصلی، این فایل‌ها را اینجا قرار دهید:

- `IRANSans-Light.woff2` (300)
- `IRANSans-Regular.woff2` (400)
- `IRANSans-Medium.woff2` (500)
- `IRANSans-Bold.woff2` (700)

برای برنامه اصلی، محل فونت‌ها `app/resources/assets/fonts/` است (نک. docs/10-ui-ux.md).
