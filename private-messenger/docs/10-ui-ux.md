# ۱۰ — طراحی UI/UX

نمونه اولیه قابل مشاهده: [`prototype/index.html`](../prototype/index.html) (ایستا، بدون سرور، فقط برای
بازبینی چیدمان و جریان‌ها؛ هیچ رمزنگاری یا شبکه‌ای در آن اجرا نمی‌شود و این موضوع روی خود صفحه نوشته شده است).

## ۱. اصول

1. **خلوت و حرفه‌ای**، RTL کامل (`dir="rtl"`، ویژگی‌های منطقی CSS مانند `margin-inline-start`).
2. **روشن/تاریک** با توکن‌های رنگ CSS؛ پیش‌فرض تابع سیستم، قابل انتخاب دستی. رنگ اصلی از پنل مدیریت قابل تغییر (متغیر `--accent`).
3. **وضعیت رمزنگاری همیشه دیدنی:** نشان قفل در سربرگ گفتگو؛ کلیک ← صفحه شماره امنیتی. هرگز حالت «بدون رمز» وجود ندارد.
4. **هشدار تغییر کلید:** نوار زرد در گفتگو + پیام سیستمی؛ برای مخاطب تأییدشده، ارسال تا تأیید دوباره قفل می‌شود.
5. **هیچ کنترل نمایشی:** قابلیت ناموجود یا پنهان است یا با توضیح غیرفعال (مثلاً «تبدیل کیفیت ویدیو در این مرورگر پشتیبانی نمی‌شود»).
6. **صداقت در محدودیت‌ها:** زمان باقی‌مانده فایل روی سرور، وضعیت «در صف/ارسال/تحویل/خوانده»، توضیح فقدان تاریخچه در دستگاه جدید.
7. **دسترس‌پذیری:** کنتراست AA، اندازه هدف لمسی ≥ ۴۴px، `aria-label` فارسی، پشتیبانی صفحه‌کلید.
8. **اعداد:** نمایش ارقام فارسی؛ ورودی OTP و شماره ارقام فارسی و لاتین را می‌پذیرد. جداکننده `·` کنار ارقام فارسی استفاده نشود (با «۰» اشتباه خوانده می‌شود — در بازبینی نمونه اولیه مشاهده شد)؛ از «،» استفاده شود.
9. **تاریخ:** تقویم شمسی با `Intl.DateTimeFormat('fa-IR-u-ca-persian')`.

## ۳. فونت IRANSans

فونت اصلی سامانه IRANSans است (مجوز تجاری توسط کارفرما تهیه شده است).
- فایل‌ها از **سرور خودِ سامانه** و فقط زیر آدرس مخفی بارگذاری می‌شوند (بدون CDN).
- محل قرار دادن فایل‌ها روی هاست: `private-messenger/app/resources/assets/fonts/`

| وزن | نام فایل (هر کدام از دو نام پذیرفته می‌شود) |
|---|---|
| 300 Light | `IRANSans-Light.woff2` یا `IRANSansWeb_Light.woff2` |
| 400 Regular | `IRANSans-Regular.woff2` یا `IRANSansWeb.woff2` |
| 500 Medium | `IRANSans-Medium.woff2` یا `IRANSansWeb_Medium.woff2` |
| 700 Bold | `IRANSans-Bold.woff2` یا `IRANSansWeb_Bold.woff2` |

- صفحه «سیستم» پنل مدیریت نشان می‌دهد کدام وزن‌ها پیدا شده‌اند.
- اگر فایلی موجود نباشد، صفحه با Tahoma نمایش داده می‌شود (خطایی رخ نمی‌دهد).
- ارقام در رابط کاربری از سمت سرور به ارقام فارسی تبدیل می‌شوند؛ نسخه FaNum فونت لازم نیست.

## ۴. نکات PWA

- `manifest.webmanifest` با `dir: "rtl"`، `lang: "fa"`، نام و رنگ از تنظیمات (تولید پویا توسط PHP).
- آیکون‌ها: 192، 512، maskable، و apple-touch-icon.
- راهنمای نصب داخل برنامه برای iOS (Share ← Add to Home Screen) با توضیح اینکه بدون نصب، اعلان و
  ماندگاری کلیدها تضمین نمی‌شود.
