# ۱۲ — راهنمای نصب روی cPanel

## روش ساده (پیشنهادی) — فقط یک فایل

**پیش‌نیاز:** SSL دامنه فعال باشد (cPanel ← SSL/TLS Status ← Run AutoSSL) و نسخه PHP دامنه 8.2 یا بالاتر باشد
(cPanel ← MultiPHP Manager). اگر هر کدام درست نباشد، خود نصب‌کننده دقیقاً می‌گوید چه کار کنید.

1. **آپلود:** cPanel ← File Manager ← پوشه `public_html` ← Upload ← فایل **`install.php`**
2. **باز کردن:** در مرورگر بزنید `https://دامنه-شما/install.php` ← دکمه **«شروع نصب»**
3. **پر کردن فرم:** فقط **رمز cPanel** (نام کاربری خودکار پر شده) و یک **رمز برای مدیر** ← **«نصب کن»**
4. **ذخیره دو آدرس** نمایش‌داده‌شده (پنل مدیریت و ورود کاربران) — تمام.

نصب‌کننده خودش این کارها را انجام می‌دهد: باز کردن فایل‌ها خارج از `public_html`، ساخت دیتابیس و کاربر دیتابیس با رمز تصادفی،
ساخت جدول‌ها، ثبت Cron، حفظ تنظیمات قبلی `.htaccess` (از جمله نسخه PHP که cPanel آنجا ذخیره می‌کند) و حذف فایل `install.php`.
رمز cPanel فقط برای همین یک بار استفاده می‌شود و هیچ‌جا ذخیره نمی‌شود.

**اگر ساخت خودکار دیتابیس کار نکرد** (مثلاً ورود دومرحله‌ای cPanel فعال است یا هاست اجازه نمی‌دهد):
cPanel ← MySQL® Database Wizard ← یک دیتابیس و یک کاربر با ALL PRIVILEGES بسازید ← در فرم نصب، بخش
«دیتابیس را خودم ساخته‌ام» را باز کنید و اطلاعات را وارد کنید.

**اگر Cron ثبت نشد:** نیازی نیست؛ کارهای نگهداری هنگام استفاده عادی از برنامه خودکار اجرا می‌شوند.

### نکته‌ها
- اگر در `public_html` سایت دیگری دارید، نصب‌کننده هشدار می‌دهد. بهتر است یک **ساب‌دامین** بسازید
  (cPanel ← Domains ← Create A New Domain) و `install.php` را در پوشه همان ساب‌دامین آپلود کنید.
- برای امنیت، `install.php` فقط تا ۲ ساعت پس از آپلود کار می‌کند و فقط مرورگری که نصب را شروع کرده می‌تواند آن را ادامه دهد.
- فونت IRANSans: فایل‌های `woff2` را در `private-messenger/app/resources/assets/fonts/` آپلود کنید (سند ۱۰، بخش ۳).

## پس از نصب
1. با آدرس پنل مدیریت وارد شوید ← «حساب من» ← ورود دومرحله‌ای (Google Authenticator) را فعال کنید.
2. «کاربران» ← «کاربر جدید» ← رمز موقت را به کاربر بدهید (در اولین ورود عوض می‌شود).
3. آدرس ورود کاربران را فقط از کانال امن به اعضا بدهید.

اگر آدرس‌ها را گم کردید: File Manager ← `private-messenger/config/.env` ← مقدارهای `APP_PATH` و `ADMIN_PATH`.

## پشتیبان‌گیری
- **دیتابیس:** cPanel ← Backup ← Download a MySQL Database Backup.
- **فایل `private-messenger/config/.env`:** کلید برنامه و رمز دیتابیس؛ نسخه پشتیبان آن را جدا و امن نگه دارید.

## روش دستی (جایگزین) — فایل ZIP

1. فایل `private-messenger-<نسخه>.zip` را در پوشه خانه (`/home/USER`، نه `public_html`) آپلود و Extract کنید.
2. یکی از دو حالت:
   - **ساب‌دامین:** Document Root ساب‌دامین را `private-messenger/public` بگذارید.
   - **دامنه اصلی:** `private-messenger/public/index.php` را به `public_html` کپی کنید و محتوای
     `private-messenger/public/.htaccess` را **به ابتدای** `.htaccess` موجود اضافه کنید (خطوط cPanel را پاک نکنید).
3. `https://دامنه/install` ← کد نصب را از فایل `private-messenger/storage/install-token.txt` وارد کنید ← فرم نصب.

| صفحه سفید | از نسخه ۰.۲.۲ به بعد به‌جای صفحه سفید علت نمایش داده می‌شود؛ اگر باز سفید است، PHP اجرا نمی‌شود — نسخه PHP دامنه را در MultiPHP Manager بررسی کنید |
| «ابتدا SSL را فعال کنید» | cPanel ← SSL/TLS Status ← Run AutoSSL |
| «نسخه PHP …» | cPanel ← MultiPHP Manager ← PHP 8.2+ |
| «رمز cPanel پذیرفته نشد» | رمز را بررسی کنید؛ اگر ورود دومرحله‌ای cPanel دارید از روش دستی دیتابیس استفاده کنید |
| «نصب در مرورگر دیگری شروع شده» | با Show Hidden Files فایل `.pm-install-claim` را در `public_html` حذف کنید |
| ریدایرکت بی‌پایان | اگر Cloudflare دارید، SSL را روی Full بگذارید |
