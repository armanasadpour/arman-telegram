# TURN رایگان با Cloudflare (بدون سرور)

Cloudflare Realtime یک سرویس TURN با سهمیه رایگان ماهانه دارد. با آن، تماس بین اینترنت همراه و شبکه‌های سخت‌گیر هم برقرار می‌شود و سرور اختصاصی لازم نیست. سهمیه و قیمت را هنگام ثبت‌نام در سایت Cloudflare بررسی کنید.

## ۱. ساخت کلید TURN در Cloudflare
1. در `dash.cloudflare.com` ثبت‌نام کنید. پلن رایگان کافی است و دامنه هم لازم نیست.
2. از منوی کناری بخش **Realtime** را باز کنید (در بعضی نسخه‌های داشبورد نامش **Calls** است) و سپس **TURN Server** را انتخاب کنید.
3. **Create** را بزنید و یک نام دلخواه بدهید.
4. دو مقدار نمایش داده می‌شود:
   - **Turn Token ID**: همان «TURN Key ID»
   - **API Token**: فقط یک بار نمایش داده می‌شود. همان لحظه کپی کنید.

نام منوها ممکن است در داشبورد Cloudflare تغییر کرده باشد. دنبال «TURN» بگردید.

## ۲. تنظیم در پنل مدیریت
پنل مدیریت ← تنظیمات ← «تماس صوتی و تصویری»:
- **نوع احراز هویت TURN:** «Cloudflare (رایگان، بدون نیاز به سرور)»
- **Cloudflare — TURN Key ID:** همان Turn Token ID
- **Cloudflare — API Token:** همان API Token
- فیلد «سرور TURN» را خالی بگذارید. نشانی سرورها از Cloudflare گرفته می‌شود.
- **سرورهای STUN:** می‌توانید خالی بگذارید. Cloudflare خودش STUN هم می‌دهد (`stun.cloudflare.com`) و STUN گوگل ممکن است از ایران در دسترس نباشد.

**ذخیره تنظیمات** را بزنید و بعد **«آزمایش STUN / TURN از همین مرورگر»** را. باید «✅ TURN کار می‌کند» ببینید. آزمایش را یک بار هم روی گوشی با اینترنت همراه انجام دهید.

## نحوه کار
- سرور شما با API Token از Cloudflare رمزهای TURN **دوازده‌ساعته** می‌گیرد، آن‌ها را چند ساعت نگه می‌دارد و به برنامه‌ها می‌دهد. **API Token هرگز به گوشی‌ها فرستاده نمی‌شود** و رمزنگاری‌شده در دیتابیس نگه داشته می‌شود.
- اگر Cloudflare لحظه‌ای در دسترس نباشد، رمزهایی که هنوز اعتبار دارند استفاده می‌شوند.
- نشانی‌های پورت ۵۳ حذف می‌شوند، چون مرورگرها آن پورت را مسدود می‌کنند و فقط اتصال را کند می‌کنند.

## اگر آزمایش خطا داد
- **«Cloudflare rejected the API token»:** Key ID یا API Token اشتباه است. دوباره بسازید و وارد کنید.
- **«cannot reach Cloudflare»:** هاست شما به `rtc.live.cloudflare.com` دسترسی ندارد. «پراکسی اعلان» در همان صفحه تنظیمات برای این درخواست هم استفاده می‌شود.
- **«✅ STUN» ولی «❌ TURN نشانی رله نداد»:** دسترسی گوشی یا مرورگر به `turn.cloudflare.com` روی آن شبکه محدود است. آزمایش را روی شبکه دیگری هم انجام دهید. اگر روی اینترنت همراه مسدود بود، سرور TURN داخلی تنها راه است (`docs/21-turn-server.md`).

## حریم خصوصی
Cloudflare فقط می‌بیند کدام IPها، چه زمانی و چه حجمی داده رد و بدل کرده‌اند. صدا و تصویر سرتاسری رمزنگاری‌شده است (DTLS-SRTP) و رله نمی‌تواند آن را باز کند. با گزینه «همه تماس‌ها فقط از طریق TURN»، IP کاربران از یکدیگر هم پنهان می‌ماند.
