# ۱۳ — گزارش فاز ۲: نصب، احراز هویت، کاربران، نشست‌ها، نقش‌ها

## ۱. تغییرات درخواستی پس از فاز ۱ (پیاده‌سازی شد)

| درخواست | وضعیت |
|---|---|
| روش ورود قابل انتخاب؛ پیش‌فرض نام کاربری و رمز عبور | ✔ سه حالت: `password` (پیش‌فرض)، `otp`، `password_otp` — فقط مدیرکل تغییر می‌دهد |
| آدرس مخفی؛ صفحه اول 404 | ✔ دو مسیر تصادفی ۱۶ کاراکتری؛ هر آدرس دیگر 404 کاملاً مشابه صفحه پیش‌فرض Apache |
| عدم ثبت در گوگل | ✔ `X-Robots-Tag: noindex…` روی همه پاسخ‌ها + meta robots؛ `robots.txt` وجود ندارد (افشاکننده بود) |
| صفحه ورود بدون نام پیام‌رسان؛ فقط نام کاربری و رمز | ✔ عنوان «ورود»، بدون لوگو/نام/favicon؛ پنل مدیریت هم همین‌طور |

جزئیات طراحی و محدودیت‌ها: [سند ۱۱](11-stealth-and-login.md).

## ۳. تست‌ها (همه اجرا شد و موفق بود)

| مجموعه | تعداد | محیط |
|---|---|---|
| واحد (`tests/run.php`) | ۱۵ | PHP 8.3 |
| سرویس‌ها با دیتابیس واقعی | ۱۱ | MariaDB 10.11 |
| انتها‌به‌انتها (`tests/Integration/e2e.php`) | ۹۸ | Apache 2.4 + mod_php 8.3 + HTTPS + `.htaccess`، **نصب از خود فایل ZIP**، در هر دو چیدمان A و B |

نمونه موارد e2e: 404 یکسان برای ۱۴ مسیر غیرمخفی (بدون کوکی)، ناشناس بودن صفحه ورود، هدرهای امنیتی،
CSRF جعلی و Origin خارجی، تغییر رمز اجباری، لغو نشست‌ها، تعلیق ← خروج فوری، قفل پس از ۱۰ خطا، هر سه حالت
ورود، شماره ناشناس بدون ارسال پیامک، cooldown، محدودیت نقش ناظر (403)، TOTP مدیر، سالم بودن زنجیره ممیزی،
Cron، و **جست‌وجوی رمزها، رمزهای موقت، راز TOTP، کوکی نشست و کدهای OTP در dump کامل دیتابیس (هیچ‌کدام یافت نشد)**.

اجرا:
```
php tests/run.php                                   # واحد
TEST_DB_NAME=… TEST_DB_USER=… TEST_DB_PASS=… php tests/run.php   # + سرویس‌ها (دیتابیس پاک می‌شود!)
php tests/Integration/e2e.php https://host /path/to/private-messenger DB USER PASS   # روی نصب تازه
```

## ۴. آنچه تست نشده یا محدودیت دارد (صادقانه)

1. **روی هاست cPanel واقعی اجرا نشده است**؛ محیط تست Apache + mod_php بود. LiteSpeed و PHP-FPM ممکن است تفاوت جزئی داشته باشند. اجرای `tools/host-probe` و سپس نصب روی هاست شما گام بعدی است.
2. **آداپتورهای کاوه‌نگار و sms.ir** طبق مستندات عمومی نوشته شده‌اند اما با حساب واقعی تست نشده‌اند (دکمه «ارسال آزمایشی» در تنظیمات برای همین است). حالت OTP با ارائه‌دهنده تست تأیید شد.
3. **پشت CDN** (مثل Cloudflare) IP واقعی کاربر دیده نمی‌شود و محدودیت نرخ IP برای همه مشترک می‌شود؛ پشتیبانی از پروکسی مورد اعتماد هنوز پیاده نشده است.
4. نمایش QR برای TOTP وجود ندارد (کلید به‌صورت متنی وارد می‌شود)؛ کتابخانه QR در فاز ۳ همراه QR تأیید دستگاه اضافه می‌شود.
5. **هنوز هیچ پیام‌رسانی یا E2EE وجود ندارد**؛ صفحه خانه کاربر صریحاً این را می‌گوید. «دستگاه» در این فاز معادل نشست است؛ کلیدهای دستگاه در فاز ۳.
6. تغییر آدرس‌های مخفی پس از نصب از پنل هنوز ممکن نیست (فقط با ویرایش `config/.env`)؛ فاز ۷.
7. فونت IRANSans تا تهیه مجوز در بسته نیست؛ فونت جایگزین سیستم/Vazirmatn استفاده می‌شود.

## ۵. ورود به فاز ۳ (پایه E2EE)

آغاز فاز ۳ با Spike مربوط به vodozemac/WASM (سند ۰۴، D1). پیشنهاد می‌کنم پیش از آن نسخه فاز ۲ روی هاست واقعی شما
نصب و بررسی شود تا محدودیت‌های واقعی (به‌ویژه Cron، HTTPS و `.htaccess`) تأیید شوند.
